# precise-qpu-simulation-extras
This project contains files for the research described in paper "Evaluating Calibration-Based Digital Twins for IBM Quantum Hardware Simulation".

File "Similaroty matrices.pdf" contains matrices for all 24 experiments.

File "Table for Shot Budget Selection.pdf" contains full table of experiments for shot count selection.

File "code_examples.ipynb" contains the code implemented during the research (including quantum circuits for the experiments).

Folder "results/counts" contains the results of experimental runs on QPUs and Noise simualtors. File "all_counts.py" contains all results, gathered from separate files located in the folder.

Folder "assets/csv_files" contains CSV calibration data, that was used when conducting experiments.
